# Simple HTTP File Browser

[English](../../README.md) | [한국어](README.ko.md) | [Español](README.es.md) | 日本語

書き込みが有効な場合、ファイルやフォルダーの行を一覧またはサイドバーのフォルダーへドラッグして移動できます。名前のクリックは従来の動作を維持します。アーカイブ内部の項目は移動できず、既存の項目は上書きしません。

Python標準ライブラリだけで動作する、外部依存のない単一ファイルのWebファイルブラウザーです。Synology File StationをイメージしたレスポンシブなSPAで、ファイルを閲覧・管理できます。

## 主な機能

- ブラウザーの「戻る」に対応したフォルダーの閲覧、検索、名前・サイズ・更新日時による並べ替え
- サイドバーのフォルダーツリーでフォルダーを展開、折りたたみ、移動
- ZIP・TAR アーカイブをディスクに展開せず、読み取り専用フォルダーとして閲覧
- サブフォルダーと空のフォルダーを含め、フォルダーを無圧縮 ZIP（`ZIP_STORED`）としてストリーミングダウンロード
- ブラウザー対応画像・音声・動画、プレーンテキスト、リンクと表を含む Markdown のプレビューとファイルのダウンロード
- HTTP バイト範囲リクエストによる音声・動画のシークと、再生失敗時の案内表示
- ファイル選択またはドラッグ＆ドロップによる複数ファイルのアップロード
- ファイルごとの進捗バー、転送済み容量、完了状態を表示するアップロードパネル
- ファイル全体をメモリに保持せずディスクへストリーミングアップロード
- フォルダー作成、名前変更、ファイルとフォルダーの再帰削除
- デフォルトは読み取り専用モード
- CLIオプションとJSON設定
- ルート外へのパストラバーサルおよびシンボリックリンクによる脱出を防止
- デスクトップとモバイルに対応したレスポンシブUI
- ブラウザー設定に応じて英語、スペイン語、日本語、韓国語を自動選択。未対応言語は英語を使用

## アーカイブの閲覧

アーカイブ名をクリックすると内部のフォルダーを閲覧でき、ダウンロードボタンで元のアーカイブを取得できます。対応形式は `.zip`、`.tar`、`.tar.gz`、`.tgz`、`.tar.bz2`、`.tbz`、`.tbz2`、`.tar.xz`、`.txz` です。

内部ではダウンロード、既存のプレビュー、サイドバーツリー、ブラウザー履歴を利用できます。アップロードを有効にしていても内部は常に読み取り専用で、アップロード・名前変更・削除・編集はできません。

フォルダーのダウンロードボタンから無圧縮 ZIP を取得できます。アーカイブ内部のフォルダーも対応し、一時 ZIP ファイルを作成せずブラウザーへ直接送信します。隠し項目は `show_hidden` 設定に従い、ファイルシステムのシンボリックリンクは除外します。

暗号化された ZIP 内部ファイルは開けません。安全でないパスとリンク項目は除外します。入れ子のアーカイブはファイルとしてダウンロードできますが、追加のフォルダーとしては開けません。大きな圧縮アーカイブは閲覧やシークに時間がかかる場合があり、圧縮方式の対応は Python の実行環境によって異なります。RAR・7z は非対応です。

## 動作要件

- Python 3.9以降
- サードパーティーパッケージ不要

## クイックスタート

プロジェクトフォルダーで次のコマンドを実行します。

```bash
python3 simple_http_file_browser.py --root /path/to/files
```

ブラウザーで次のURLを開きます。

```text
http://localhost:8000
```

デフォルトでは、すべてのネットワークインターフェース（`0.0.0.0`）で待ち受け、読み取り専用で動作します。

### 書き込み操作を有効にする

```bash
python3 simple_http_file_browser.py \
  --root /path/to/files \
  --port 8080 \
  --upload
```

### 別の端末からアクセスする

```bash
python3 simple_http_file_browser.py \
  --port 8080 \
  --root /path/to/files
```

別の端末から `http://SERVER_IP:8080` を開きます。

## CLIオプション

```text
--config PATH  JSON設定ファイル（デフォルト: config.json）
--host HOST    バインドアドレス（デフォルト: 0.0.0.0）
--port PORT    サーバーポート（デフォルト: 8000）
--root PATH    アクセス可能な最上位フォルダー（デフォルト: 現在のフォルダー）
--upload       アップロードとファイル管理を有効化
--read-only    書き込み操作を無効化
--version      バージョンを表示
```

設定の優先順位は、CLIオプション、JSON設定ファイル、プログラムのデフォルト値です。

## JSON設定

```bash
cp config.example.json config.json
python3 simple_http_file_browser.py
```

```json
{
  "host": "0.0.0.0",
  "port": 8000,
  "root": ".",
  "upload": false,
  "title": "My File Station",
  "show_hidden": false,
  "max_upload_mb": 512,
  "overwrite": false
}
```

| 項目 | 説明 |
|---|---|
| `host` | サーバーが待ち受けるアドレス |
| `port` | サーバーポート |
| `root` | ブラウザーからアクセスできる最上位フォルダー |
| `upload` | 書き込み操作を有効にするかどうか |
| `title` | Web画面に表示するタイトル |
| `show_hidden` | `.` で始まる名前を表示するかどうか |
| `max_upload_mb` | HTTPリクエストごとの最大アップロードサイズ（MB） |
| `overwrite` | 同名の既存ファイルを上書きするかどうか |

別の設定ファイルを使う場合は `python3 simple_http_file_browser.py --config /path/to/config.json` を実行します。

## 削除動作

- ファイルは即座に削除されます。
- フォルダーを削除すると、中のファイルとサブフォルダーも再帰的に削除されます。
- シンボリックリンクはリンク先をたどらず、リンク自体だけを削除します。
- ごみ箱や復元機能はありません。

## セキュリティ

このサーバーにはユーザー認証やHTTPSは組み込まれていません。デフォルトの`0.0.0.0`は利用可能なすべてのネットワークインターフェースでサーバーを公開するため、信頼できるネットワークだけで使用してください。同じコンピューターからのアクセスだけに制限するには、`--host 127.0.0.1`を指定します。書き込み操作は必要な場合だけ有効にしてください。インターネットに公開する場合は、認証とTLSを設定したリバースプロキシの背後で実行してください。`root`には必要最小限のフォルダーを指定してください。

## サーバーの停止

実行中のターミナルで `Ctrl+C` を押します。
